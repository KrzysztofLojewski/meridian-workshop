Frontend

  • Vue 3 Composition API throughout
  • vue-router for single-page routing
  • axios for all API calls
  • Custom composables for shared state
  • EN/JA internationalization (useI18n)
  • Scoped CSS per component

Backend

  • FastAPI with automatic OpenAPI docs at /docs
  • Pydantic models for all request/response shapes
  • CORS open for all origins (dev config)
  • uv for Python dependency management
  • Data loaded from JSON files at startup, held in memory
  • No database, no auth (see limitations)

Filter Data Flow

How a warehouse selection in the top filter bar reaches the backend and updates the UI.

1
User selects a filter
FilterBar.vue — dropdown bound via v-model to shared ref in useFilters() composable
2
Shared state updates
useFilters.js holds module-level refs (selectedLocation, selectedCategory, selectedPeriod, selectedStatus) — shared across all components as a singleton
3
View detects change
Each view watches the relevant filter refs via watch() and calls its loadData() function
4
API call with params
api.js converts filters to URLSearchParams — e.g. ?warehouse=London&category=sensors
5
Backend filters in memory
apply_filters() in main.py iterates the in-memory list and returns matching items. Month/quarter filtering handled separately by filter_by_month()
6
UI re-renders
View updates its reactive ref, Vue re-renders the table or chart automatically

Running the Application

Backend

  • cd server
  • uv run python main.py
  • Runs on http://localhost:8001
  • API docs at http://localhost:8001/docs

Frontend

  • cd client
  • npm install
  • npm run dev
  • Runs on http://localhost:3000

Run tests

  • Backend: cd tests && uv run pytest -v
  • E2E browser: cd tests/e2e && npx playwright test

Current Limitations & Production Readiness

⚠ This system is not production-ready. The following must be addressed before go-live:
  • No authentication — any user can access all data. Add JWT or session-based auth.
  • No database — data is read from JSON files at startup and held in memory. Changes don't persist across restarts. Replace with PostgreSQL or similar.
  • CORS open to all origins — restrict to Meridian's internal domain before deployment.
  • No HTTPS — must be enforced in production.
  • No rate limiting or input validation beyond types — add before exposing externally.
  • Purchase orders unimplemented — the data file exists but the creation flow is not wired end-to-end.
